Demo_Ecom a small, honest shop

The shop lives in one repository

A shop counter you can run yourself.

Demo_Ecom is a small Indian shop distributed as source, not as a hosted storefront. You install it with Node.js 20 and PostgreSQL, run the migration and seed, and the catalogue, cart, checkout and admin open on your own machine. The same lockfile, migration and seed give the same starting shelf wherever it runs.

  1. Install the locked dependencies npm ci
  2. Set up PostgreSQL and copy the example settings cp .env.example .env
  3. Create the tables and the starting catalogue npm run migrate && npm run seed
  4. Open the shop at localhost:3000 npm run dev

What this page is

This is the release marker for the Firebase Hosting site. The shop is not served from here: it runs where its PostgreSQL database and Node.js server run, on a machine you control.

Prices are kept in integer paise and shown in rupees. The server calculates every total, and payment happens inside Razorpay's hosted Checkout, so the shop never receives card details.
